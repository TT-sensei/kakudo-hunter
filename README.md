# kakudo-hunter

角度を見抜いてナビアンをつかまえる、タブレット向けの角度学習教材です。

## モンスター

ナビキャラクター素材集 `TT-sensei/navi-character-` のファンタジーモンスターを使用しています。

- レベル1：ナビアン（ザコ）
- レベル2：エボナビ（ザコエボル）
- レベル3：ボスナビ（ボス）

ナビアン・エボナビは、navi-character- のモンスターグループ1を中心に収録しています。ボスナビは進化系との1対1対応を前提にせず、グループ1のボスを独立したモンスターとして扱います。

現在の収録数は74体です。

- レベル1 ナビアン：37体
- レベル2 エボナビ：24体
- レベル3 ボスナビ：13体

画像パス、表示名は `navi-character-` の公開カタログを基準にしています。画像は教材側へコピーせず、既存のWeb配信用素材を参照します。

## 図鑑

「ナビアン図鑑」では、レベル1〜3を分けて表示します。過去の `angleHunter.navianGets.v1` の捕獲記録も、既存のナビアンについては引き継ぎます。

## 開発方針

- GitHub Pagesで動作する静的HTML/CSS/JavaScript
- 外部APIやAPIキー、バックエンドは使用しない
- タブレットで操作しやすい大きなUI
- 角度を読む学習を主役にし、キャラクターは教材体験を補助する
- 共有素材は `navi-character-` の既存Web素材を利用する
