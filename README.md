# kakudo-hunter

角度を見抜いてナビアンをつかまえる、タブレット向けの角度学習教材です。

## モード

- ハンターモード：円形フィールドで、ナビアンが止まった角度をボタンで選ぶ（30°・15°）。1°は分度器モードになる
- チャレンジモード：60秒で何体つかまえられるかに挑戦
- あてようモード：分度器を自分で指で動かして当てるモード。分度器の本体をドラッグで移動、縁や金色のつまみをドラッグで回転させ、中心を頂点に・0°の線をはじめの辺に合わせると吸着する（向きが反対のときは案内が出る）。合わせ終わってから目盛を読んで数字で答える。間違えたときは「当て方」と「読み方」でフィードバックを分けて返す。きざみは30°・15°・1°から選べる

## 出題の見せ方

全モード共通で、ナビアンがはじめの辺から動いて角度が「開く」アニメーションで出題します。角度を「2つの辺の開き具合」としてイメージできるようにするための見せ方です。

## モンスター

ナビキャラクター素材集 `TT-sensei/navi-character-` のファンタジーモンスターを使用しています。

- レベル1：ナビアン（ザコ）
- レベル2：エボナビ（ザコエボル）
- レベル3：ボスナビ（ボス）

ナビアン・エボナビは、navi-character- のモンスターグループ1を中心に収録しています。ボスナビは進化系との1対1対応を前提にせず、グループ1のボスを独立したモンスターとして扱います。

現在の収録数は61体です。

- レベル1 ナビアン：24体
- レベル2 エボナビ：24体
- レベル3 ボスナビ：13体

画像パス、表示名は `navi-character-` の公開カタログを基準にしています。画像は教材側へコピーせず、既存のWeb配信用素材を参照します。

## 図鑑

「ナビアン図鑑」では、レベル1〜3を分けて表示します。捕獲記録は現在のグループ1だけを対象にします。旧バージョンの捕獲記録は引き継ぎません。

## サウンド

`sounds-recipe-` の実在する音IDをWeb Audio APIで利用しています。正解・不正解・開始・終了・操作・図鑑オープンなどに短い効果音を入れ、画面上の「音」ボタンでミュートできます。音がなくても角度学習そのものは成立する設計です。

## 開発方針

- GitHub Pagesで動作する静的HTML/CSS/JavaScript
- 外部APIやAPIキー、バックエンドは使用しない
- タブレットで操作しやすい大きなUI
- 角度を読む学習を主役にし、キャラクターは教材体験を補助する
- 共有素材は `navi-character-` の既存Web素材を利用する
